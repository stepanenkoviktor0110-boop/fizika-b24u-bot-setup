## Анализ FAIL

### C2 «сколько двушек Моисеенко с чистовой отделкой»

Бот возвращает буквально:
```
"К сожалению, по вашему запросу сейчас нет подходящих вариантов. Оставьте контакт — менеджер подберёт варианты вручную и свяжется с вами."
```

(заключено в двойные кавычки — это не сгенерированный LLM-ответ, а цитата из конфига).

**Проверено:**
- Перебор формулировок (с «?» и без, разный `visitor_id`) — тот же ответ.
- В кабинете обыскан весь UI (Главная, Сообщения, Обучение, Уведомления, Установка, Тариф) — поля для редактирования этого текста нет ни в одной секции.
- Промпт-правка с явным «НЕ уходи в "нет данных"» не помогла.

**Вывод:** это backend-fallback на стороне Flynn-runtime, срабатывает когда RAG возвращает 0 матчей по строгому фильтру («чистовая отделка» в Моисеенко 10 — там реально White Box / предчистовая). Не лечится из кабинета.

**Что можно делать дальше:**
- (a) Запросить у Flynn-команды отключение/редактирование backend-fallback.
- (b) Workaround в фиде: расширить `RENOVATION_LABELS` для Моисеенко 10, чтобы «чистовая» лексически матчилось на White Box / предчистовая. Это уже частично сделано, но не помогло — значит либо синонимы не попадают в нужный chunk, либо ranker отбрасывает.
- (c) Добавить TEXT-карточку в KB: «Отделка в ЖК Моисеенко 10» — описать что White Box = предчистовая = «под ключ нет, но почти готовая». При запросе про «чистовую» она поднимется в Top-N и бот процитирует, не уходя в fallback.
